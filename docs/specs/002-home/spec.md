## 산식 검증 결과 (2026-08-20)

**계수는 맞았다.** `architecture.md` §5.4에 적혀 있던 식이 기상청 2022년 6월 개정식과 일치한다.

**디자인 수치는 틀렸다.** `기온 31.5℃ · 습도 78%`의 실제 체감온도는 **33.5℃**이며
Figma의 34.2℃는 0.73℃ 어긋난다. 프로토타입이 세 값을 따로 하드코딩한 결과다.
**단계는 3단계로 동일하므로 이 스펙의 전제는 바뀌지 않는다.**

**풍속은 산식에 들어가지 않는다.** 여름철 체감온도는 기온과 습도만 쓴다.
`05 등급 상세`가 풍속을 기여 요인으로 보여주므로 문구로 구분해야 한다 —
습도는 체감온도에 들어가고, 풍속은 추천에만 쓰인다. §6에 반영했다.

남은 것 — 기상청 페이지 눈확인, 여름철 산식의 적용 범위 확인 (§5.4 경고).

## 1. 문제

001에서 사용자가 민감도를 답했지만, 그 값으로 계산한 결과를 볼 화면이 없다.
지금 앱은 임시 화면에 단계 숫자만 띄운다.

정작 사용자가 알고 싶은 건 세 가지다 — **오늘 얼마나 땀이 날까**, **왜 그런가**,
**하루 중 언제가 제일 힘든가.**

## 2. 이 기능이 끝나면

앱을 열면 지금 있는 곳의 관측값으로 계산한 오늘의 땀 단계가 마스코트와 함께 뜬다.
왜 그 단계인지 궁금하면 한 번 눌러 기온·습도·풍속의 기여도를 본다.
아래로 내리면 시간별·주간 예보가 같은 단계 기준으로 보인다.

## 3. 사용자 시나리오

### 주 시나리오
```
Given  온보딩을 마쳤고 위치 권한을 허용했다
When   앱을 연다
Then   현재 위치의 관측값으로 계산한 단계·멘트·마스코트가 보인다
```

```
Given  홈에서 "더 알아보기"를 누른다
When   등급 상세가 열린다
Then   체감온도·습도·풍속이 각각 얼마나 기여했는지 보인다
```

### 예외
| 상황 | 결과 |
|---|---|
| 위치 권한 거부 | 지역을 직접 고르게 하고, 그 지역 관측값으로 계산한다 |
| 날씨 조회 실패 | 마지막 성공값 + `n분 전` 배지. 빈 화면을 만들지 않는다 |
| 네트워크 없음 | 위와 같다 |
| 캐시도 없는 첫 실행 | 관측값 자리에 로딩, 마스코트는 중립 상태 |

# 구현 계획

> 여기서부터는 *어떻게*다.

## 10. 접근

### 날씨 소스는 하나다 — WeatherKit

기온과 습도를 받아 **기상청 산식으로 우리가 체감온도를 계산한다.**

기상청 초단기실황도 체감온도를 주지 않는다. 기온·습도만 있으면 되고 WeatherKit이
그 둘을 준다. 격자 변환·발표 시각·카테고리 파싱·인증키가 전부 사라진다.

**숫자의 기준은 바뀌지 않는다.** 체감온도는 여전히 기상청 2022년 개정식이다.

화면이 소스를 모르게 하는 구조는 유지한다. `WeatherRepository`가 값에 출처를 달아
내려보내므로, 나중에 기상청 실황을 1순위로 얹어도 화면은 바뀌지 않는다.

### 체감온도는 도메인에서 계산한다

산식은 순수 함수다. 기온·습도만 있으면 계산되고 네트워크가 필요 없다.
`SweatDomain`에 넣어 시뮬레이터 없이 검증한다.

**WeatherKit이 주는 체감온도는 쓰지 않는다.** 산식이 달라서 그대로 쓰면 단계 기준이
둘이 된다. 기온·습도만 받아 우리가 계산한다.

### 예보도 같은 엔진을 쓴다

시간별·주간 예보의 단계도 `SweatStageEngine`이 계산한다. 예보 전용 로직을 따로 만들지 않는다.
Figma의 `Weather Face` Level 1~4는 6단계를 4구간으로 묶은 표시용이며,
그 매핑도 도메인에 둔다.

### 검토했지만 택하지 않은 것

- **기상청 1순위 + WeatherKit 폴백** — 원래 계획이었다. 기상청도 체감온도를 주지
  않아 기술적 이득이 없는데 격자 변환·발표 시각·인증키를 전부 떠안는다
- **기상청 단독** — 위와 같은 비용에 장애 시 대안까지 없다
- **예보용 별도 단계 로직** — 홈과 예보의 단계가 어긋나면 사용자가 먼저 알아챈다

## 12. 출처 표기

**법적 요건이다.** WeatherKit은 Apple Weather 표기와 법적 링크를 요구한다.

값마다 출처를 들고 다니게 하고 화면이 그것을 표시한다. 지금은 소스가 하나뿐이라
과해 보이지만, 기상청을 나중에 얹을 때 화면을 고치지 않기 위해서다.

**정확한 표기 형식은 구현 전에 확인한다.** 문구를 추측해서 넣지 않는다.

## 15. 테스트 계획
